# ScanSklad OCR LAB 0.1 — отдельный тест распознавания кириллицы

**Это НЕ обновление рабочего ScanSklad v2.0.** Это совершенно отдельное Android-приложение с идентификатором `com.scansklad.ocrlab`. Оно не меняет и не читает данные рабочего приложения.

## Что делает

- Показывает камеру и красную рамку для **одной строки** складского адреса.
- По кнопке **СКАНИРОВАТЬ** читает **один и тот же кадр** двумя распознавателями:
  1. **PaddleOCR PP-OCRv5 Cyrillic** (русские буквы; ONNX модель),
  2. **Google ML Kit Latin** (тот же OCR-движок, что и в основной Android-версии; **без** её последующей нормализации и подстановок).
- Показывает исходный распознанный текст, уверенность PaddleOCR (не гарантия правильности), время каждого распознавания.
- Кнопка **АВТО** запускает периодические попытки, если нужна проверка стабильности. Автоматически сохранять ошибочные адреса она **не будет**.
- Можно вписать то, что **на самом деле написано на этикетке**, нажать **ЗАПОМНИТЬ ТЕСТ**, а затем **ОТПРАВИТЬ ОТЧЁТ**. Отчёт сохранён локально даже при перезапуске приложения.
- Нет `INTERNET` permission. После сборки все модели включены в APK и тест не требует сети.

Важное ограничение: модель PaddleOCR здесь **распознаёт уже выделенную строку**, а не выполняет поиск текста по всему фото. Поэтому рамка должна охватывать именно одну строку, а не несколько этикеток. Это правильный первый этап проверки **различимости Л/П и цифр**, прежде чем усложнять рабочее приложение полноценным поиском строк.

## Как получить APK без Android Studio

1. На GitHub создайте **новый** репозиторий, например `ScanSklad-OCR-Lab` (НЕ в `ScanSklad`!).
2. Распакуйте этот ZIP. На странице нового репозитория нажмите **uploading an existing file**.
3. Перетащите **содержимое** папки проекта в GitHub: `app/`, `scripts/`, `.github/` и файлы `build.gradle`, `settings.gradle`, `gradle.properties`, `README_RU.md`.
4. Если папка `.github` не загрузилась (она скрытая), перейдите **Actions → set up a workflow yourself**, укажите имя `.github/workflows/build-apk.yml`, вставьте содержимое файла `WORKFLOW_ДЛЯ_КОПИРОВАНИЯ.txt` и нажмите Commit.
5. На вкладке **Actions** откройте **Build PaddleOCR Test APK**. В первой сборке GitHub скачает официальную модель **cyrillic_PP-OCRv5_mobile_rec_onnx** (около 8 МБ) и словарь, затем соберёт Android APK.
6. Когда будет зелёная галочка, скачайте артефакт `ScanSklad-PaddleOCR-Lab-debug-APK`, распакуйте ZIP и установите `app-debug.apk` на Android. **Рабочий ScanSklad удалять не надо.**
7. Предоставьте разрешение на камеру.

Если сборка не прошла, отправьте мне лог красного шага. Если PaddleOCR при запуске покажет ошибку словаря или формы вывода, пришлите текст ошибки с экрана; не используйте некорректное распознавание для складского учёта.

## Как тестировать, чтобы сравнение было честным

1. Распечатайте или покажите на другом экране `142/Л10/1`. Наведите только эту строку в красную рамку. Нажмите **СКАНИРОВАТЬ** и подождите ответ обоих движков.
2. В поле **Что написано на этикетке?** введите `142/Л10/1`. Нажмите **ЗАПОМНИТЬ ТЕСТ**.
3. Повторите для `142/П12/1`, `142/П1/1`, `142/Л3`, `162/шкаф4`, `148/сейф2`, `136/10/5`, `152/1`. Важно проверять несколько расстояний и освещений.
4. Нажмите **ОТПРАВИТЬ ОТЧЁТ** и перешлите результаты в наш чат.

Это эксперимент: **точность и скорость на реальных устройствах пока не проверены**. Мы не будем встраивать модель в рабочую v2.0 до испытаний.

## Источник модели и лицензия

- Официальная ONNX-модель: https://huggingface.co/PaddlePaddle/cyrillic_PP-OCRv5_mobile_rec_onnx (Apache-2.0).
- Описание русского распознавателя: https://huggingface.co/PaddlePaddle/cyrillic_PP-OCRv5_mobile_rec.
- Движок ONNX Runtime Android: https://onnxruntime.ai/.
- Google ML Kit Android Latin: https://developers.google.com/ml-kit/vision/text-recognition/v2/android.

Модель не включена в исходный ZIP и загружается **автоматически при сборке APK в GitHub Actions**. Папка `app/src/main/assets/rec/` после этого содержит `inference.onnx` и `inference.yml`. Обычная загрузка исходников в GitHub не требует вручную скачивать модель.
